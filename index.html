Features

Everything a devlog needs

From the first screen recording to the final export, in a single native app.

🎥

Screen recording

Capture a display or window at native resolution in HEVC or ProRes, with system audio, a separate mic track and an optional camera.

🖱️

Smooth cursor and auto zoom

The cursor is recorded separately and redrawn smoothly. Zooms are generated from your clicks, and every one is editable.

🖥️

Live Video desktops

Tell stories on a simulated desktop with windows, a dock, a menu bar, a scripted cursor, AI chats, terminals and notifications.

⌨️

Scripted scenes

Write animations in TypeScript and JSX with a Motion Canvas–style API, or wire them up visually in the node editor.

💬

On-device captions

Transcribe speech on your Mac into styled captions with the spoken word highlighted. Export SRT files too.

🤖

Assistant and MCP

Built-in Assistant with your own Anthropic key, plus a local MCP endpoint so other agents can edit and export your project.

Edit

A timeline that stays out of your way

Multi-track editing with keyframes, easing curves, speed regions and snapping. Split, trim, ripple and duplicate with the shortcuts you expect.

  • Drag above the top track to make a new one
  • Filmstrips and waveforms on every clip
  • Export H.264, HEVC, ProRes or animated GIF
Animate

Keyframe anything

Click the diamond next to any property to add a keyframe at the playhead. Shape the bezier curve in the Keyframes editor, or start from an animation preset.

  • Position, scale, rotation, opacity and blur
  • Drag keys directly on the curve
  • Presets write keyframes you can refine
Live Video

Directed cursor, believable desktops

Plan timed cursor actions like move, click, drag, type and scroll. Veenie works out the path and what each action does to the windows, live, so nothing is baked into keyframes.

  • Timed focus, minimize, maximize and close
  • Streaming AI chat replies and terminal output
  • Templates for investigations, group calls and late-night chats
Captions

Captions that follow the voice

Generate captions on device with the Speech framework. Pick a style and the word being spoken is highlighted as it plays.

  • Nothing leaves your Mac
  • Audio visuals: waveform, bars, spectrum and pulse
Code clips

Show code the way you mean it

Pick a language and theme, spotlight specific lines with Focus Lines, and animate Reveal for a typewriter effect.

  • Syntax highlighting via highlight.js
  • Animate focus to guide the viewer's eye
Scripting

Motion graphics as code

Script clips use TypeScript and JSX with signals, generator flow, flex layout and code morphing. Scenes are simulated once and drawn at output resolution, so they stay sharp at any export size.

Prefer not to write code? Switch any scene to Nodes and wire objects, animations and values together. It compiles to the same script.

// A scene is a generator.
yield* code().selection(lines(1, 2), 0.6);
yield* all(
  title().opacity(1, 0.4),
  card().position.y(0, 0.6),
);
Shading

Shader graphs for the finishing touch

Scenes can draw project shader graphs with the <Shader> component, so effects live right next to your animation.
